**Native WhatsApp on Windows 11 without requiring OpenGL 2.1.** This personal
ZapFast fork switches the Windows renderer to **Direct3D 12/WARP** for the
tested Intel N95 PC using Microsoft Basic Display Adapter. WARP can render
on the CPU. AI assistance credit: **GPT-6.1 Sol (medium)**.

Extract the ZIP and open `zapfast.exe`; the `.cmd` launcher forces CPU WARP.

## New

- **DX12/WARP compatibility for the tested PC.** Windows 11 Pro x64,
  Intel N95, about 16 GB RAM, and a 1280x800 desktop at 100% scaling.
- **Less work when drawing large chat lists.** Only viewport rows are copied,
  and contact search avoids repeated chat scans. With 10,000 synthetic chats,
  list preparation changed from 88.9 to 18.5 ms in the development measurement.
  This measures that stage in debug code, not overall application speed.

## Fixed

- **An expired QR can be renewed by retrying**, preserving the saved session.
  Stale attempts and expired phone-link codes are discarded.
- **The Messages theme draws a DX12-compatible header.**
- **Official updates are disabled for this variant** to preserve its Windows
  graphics adaptation. Fork updates are manual.

## Validation and limits

Formatting, Clippy, and documentation passed. Windows test suites passed
1,867 and 1,869 tests with zero failures and 13 explicitly ignored tests per
suite. The synthetic performance test was run separately. Seven graphics
cases passed with DX12. QR receipt, expiration, and retry were checked with
a temporary profile in .2, whose pairing code is retained. Account approval
and real message delivery require the owner's phone. Other PCs, Linux,
macOS, cameras, and microphones need independent validation.
